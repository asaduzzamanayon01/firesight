Updated 30 October 2026. About 75–90 seconds; agree the allocation with Tabib and rehearse personally.

My contribution covers the data catalogue, provenance and quality checks. We have now received six seasonal event tables and five raw weather batches, described by the sender as real FIRMS and Open-Meteo data.

The event files contain 2,846 supplied event rows. Their required fields, timestamps, duplicates and coordinates pass our structural checks. With the current main grid, these become 2,822 positive cell-days, or about 0.08174 percent. These are satellite-derived labels, not independently confirmed ignition causes.

All 56 weather points have complete daily and hourly coverage, with no missing numeric values. I reconstructed the processed weather using the existing main transformations and retained the input hashes. That reconstruction has about 3.45 million cell-days, but 35 grid centres fall outside the configured boundary. The checker keeps this as a failure for the team to resolve.

We still need the actual forecast export, run provenance and an agreed grid and day convention before final acceptance. This audit does not reproduce model accuracy, and historical reanalysis should be presented as retrospective input.
