My contribution covers the data catalogue and quality checks. The two sources in the final plan are NASA FIRMS detections and historical weather from Open-Meteo.

For each acquired file, the catalogue specifies the source, period, units and attribution. The quality module checks required fields, missing values, duplicate records, timestamps and coordinates. At the dashboard boundary, it also validates probabilities and binary labels in forecast.csv.

The checks preserve the input files and produce aggregate counts with input hashes. I have tested the module offline on controlled fixtures. Integration and the real-data quality summary still need the actual run files.

Satellite detections are not independently verified ignition events, and historical reanalysis availability must be considered before making live forecasting claims.
